## Summary

GSD runs each phase as discuss, research, plan, plan-check, execute, verify, UAT and gap closure. Markdown workflows orchestrate; spawned agents (gsd-planner, gsd-plan-checker, gsd-executor, gsd-verifier) do the work; CJS modules (phase.cjs, commands.cjs, init.cjs) and sdk/src/phase-runner.ts compute waves, status and numbering. Plans are PLAN.md files with YAML frontmatter and 2-3 XML tasks; waves come from a Kahn topological sort of depends_on. Gates are blocking (decision coverage, cycle errors, verification status tree) or advisory (code review, drift, debt warnings). Contradictions: waves are described as precomputed but recomputed in code; revision caps differ across docs; the status regex is not frontmatter-scoped. Milestone archiving was read only in part. Static reading only; nothing was executed.

## Numbering rules

- Phase directories are NN-slug with a padded two-digit integer (discuss-phase.md 117, 376-383; insert-phase.md 103).
- Decimal phases NN.M are used for urgent inserts between NN and NN+1. phase.next-decimal scans directory names, and the example 06.3 follows existing 06.1 and 06.2 (decimal-phase-calculation.md 5-30; phase.cjs 148-160).
- Decimal inserts never renumber integer phases; guidance says not before phase 1 (insert-phase.md 135).
- Removing an integer phase renames later phase directories and files on disk and rewrites ROADMAP (phase.cjs 1037-1049; remove-phase.md 141-143 forbids manual renumbering).
- Plan files are NN-MM-PLAN.md with a two-digit MM; new gap-closure plans take the next number after existing ones (planner-gap-closure.md 23).
- A plan may be referenced by canonical prefix 03-01 or full stem 03-01-auth-hardening (phase.cjs 463-464; gsd-planner.md 429).
- wave defaults to 1 for the lowest level when no plan declares wave 0; it is 0 when any plan declares wave 0 (phase.cjs 507-509, 526).
- Decision IDs are D-NN; alphanumeric IDs such as D-INFRA-01 are also accepted (decisions.cjs 11-14; templates/context.md 57-61).
- Requirement IDs come from the ROADMAP Requirements line with brackets stripped (gsd-planner.md 618-619).
- Gap-closure phases from a milestone audit are numbered after the highest existing phase directory (plan-milestone-gaps.md 68-72).
- Milestone archive names use the version prefix, for example v1.0-ROADMAP.md and v1.0-phases (milestone.cjs 94, 163-176, 245).
